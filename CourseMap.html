Twelve steps from your first container to a real online shop running on Amazon EKS. Every module adds one layer to the same system, so by the end you've built — and broken, and fixed — a production platform.

Where you'll end up

Real problems, real fixes

The capstone wasn't scripted to go smoothly. These came up while building it, and each fix is in the code, the guide and the runbooks — the kind of story interviewers ask for.

Drain

An api Pod got stuck during a zone drain

→ nodeTaintsPolicy: Honor

Release

40 of 539 requests failed in a one-step release

→ three-phase blue/green: 0 errors

Drill

Every api and worker Pod crashed when Postgres restarted

→ pool error handler + requeue: 0 restarts

GitOps

Pausing one Argo CD app didn't stick

→ pause the parent first

Security

13 critical CVEs in the web image

→ patched base, curl removed: 0 findings

AWS

Karpenter couldn't launch Spot nodes

→ one-time service-linked role
